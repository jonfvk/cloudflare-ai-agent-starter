# Cloudflare AI Agent Starter Kit

A starter project demonstrating how to build and deploy a simple AI-native application using Cloudflare Workers AI and Durable Objects.

## Problem

Developers need easy entry points to build globally distributed AI-powered apps leveraging modern edge infrastructure.

## Approach

Provide a minimal example app with AI agent integration, persistent state, and global deployment on Cloudflare platform.

## Milestones

1. Set up Cloudflare Workers project
2. Integrate Workers AI for AI model calls
3. Implement Durable Objects for session state
4. Add Workers KV for persistent storage
5. Create simple web frontend to interact with AI agent
6. Implement basic API gateway for requests
7. Add logging and error handling
8. Test global deployment and latency
9. Document deployment and usage steps
10. Publish example repository and demo
